# Kushal Chakrabarti — Academic Website

A dependency-free static academic website designed for free hosting on GitHub Pages.

## Files

- `index.html` — homepage
- `publications.html` — publication list with topic filters
- `style.css` — responsive styling
- `script.js` — mobile navigation + publication filters
- `assets/favicon.svg` — favicon
- `assets/headshot.jpg` — **add your headshot here** (not included in the package)

## Add the headshot

Save the photograph as exactly:

```text
assets/headshot.jpg
```

The homepage already contains the image frame and crop styling. Until that file is added, a neutral placeholder is shown. A portrait-oriented JPG works best; the page uses `object-fit: cover`, so no manual resizing is required.

## Recommended deployment: GitHub Pages

1. Create a public GitHub repository named `<your-github-username>.github.io`.
2. Upload the contents of this folder to the repository root and commit them.
3. In the repository, open **Settings → Pages**.
4. Configure Pages to deploy from the `main` branch and the repository root if it is not already active.
5. The site will be available at `https://<your-github-username>.github.io/` after deployment completes.

You can later connect a custom domain without changing the website code.
